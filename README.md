# IMDb Movie Industry Analysis

## Project Overview

This project analyzes an IMDb movie dataset containing information on movie ratings, budgets, revenues, genres, and audience engagement metrics.

The objective is to identify factors associated with movie success and uncover insights that could support decision-making within the film industry.

---

## Business Question

What characteristics are associated with commercially successful and highly rated movies?

Key areas investigated include:

* Budget vs Revenue
* Genre Performance
* Director Performance
* Audience Engagement
* Rating Distributions

---

## Dataset

Source: IMDb Movies Dataset

Records: ~2,900 movies

Features include:

* Movie Title
* Genre
* Director
* Budget
* Gross Revenue
* IMDb Rating
* Number of Votes
* Cast Popularity Metrics

## Key Insights

* Higher production budgets generally correspond with higher revenues.
* Movie performance varies substantially across genres.
* Revenue distributions are heavily influenced by blockbuster films.
* Audience engagement metrics provide additional insight into movie success.
